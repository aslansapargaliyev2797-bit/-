# Скрининг здоровья сотрудников — статистика

Веб-дашборд по результатам анкетирования сердечно-сосудистого риска. Данные
подтягиваются напрямую из Google Таблицы (лист `ANSWERS`) и агрегируются на
сервере — наружу отдаётся только сводная статистика, без email/ФИО.

## Разделы

- **Общее** — 16 блоков статистики (ключевые показатели, уровень риска, ИМТ,
  курение, питание, активность, осведомлённость, факторы риска и т.д.) — та
  же структура, что и на листе «Статистика» в исходной таблице. Сверху —
  каскадный выбор: филиал → структурная единица (ЛПУ/АУП) → служба
  (ЛЭС/ГРС/ЭХЗ/...), статистика пересчитывается под выбранный срез.
- **Филиалы** — рейтинг «самые проблемные филиалы» с переключаемой метрикой
  (28 метрик на выбор), таблица, разбивка по ЛПУ/структурным единицам внутри
  каждого филиала, ссылка на полную статистику по нему на «Общее».
- **Комбинированно** — тепловая карта филиал × служба с фильтрами и
  детализацией по клику на ячейку.

Отдельной вкладки для сравнения служб между собой нет — служба сама по себе
(без привязки к филиалу) не даёт осмысленного сравнения (одна и та же служба
в разных филиалах — это разные условия). Смотреть её стоит либо внутри
конкретного филиала («Общее» → выбрать филиал → выбрать службу), либо в
разрезе филиал × служба («Комбинированно»).

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. По умолчанию используется таблица, ID которой
зашит в `lib/data.ts` (публичная, доступна по ссылке). Чтобы указать другую
таблицу — скопируйте `.env.example` в `.env.local` и подставьте свой
`GOOGLE_SHEET_ID` / `GOOGLE_SHEET_TAB`.

Таблица должна быть расшарена как «Доступ по ссылке — Читатель», иначе сервер
не сможет её прочитать.

## Деплой

Проект — обычное Next.js-приложение, деплоится куда угодно, где есть Node.js
(Vercel, Netlify, свой сервер). Проще всего — Vercel:

1. Зайдите на vercel.com, New Project → импортируйте этот репозиторий/ветку.
2. При необходимости добавьте переменные окружения `GOOGLE_SHEET_ID` /
   `GOOGLE_SHEET_TAB` (см. `.env.example`) — если таблица та же, можно
   ничего не добавлять.
3. Deploy. Готово — сайт будет сам подтягивать новые анкеты (кэш на сервере
   обновляется каждые 5 минут).

## Как это устроено

- `lib/data.ts` — серверная загрузка и парсинг CSV-экспорта таблицы
  (`docs.google.com/.../gviz/tq?tqx=out:csv`). Вызывается только на сервере —
  сырые данные (в т.ч. пустая колонка email) в браузер никогда не попадают.
- `lib/parseBranch.ts` — разбор поля «Филиал» на филиал + структурную единицу
  (ЛПУ/АУП), т.к. в анкете они записаны одним текстом («03. УМГ Атырау ЛПУ
  Индер»).
- `lib/aggregate.ts` — расчёт всех 16 разделов статистики по произвольному
  срезу анкет.
- `lib/ranking.ts`, `lib/matrix.ts` — группировка по филиалу/подразделению и
  сборка матрицы для тепловой карты.
- `components/` — переиспользуемые визуальные блоки (плитки, ранжированные
  бары, тепловая карта, распределение по уровню риска и т.д.).
